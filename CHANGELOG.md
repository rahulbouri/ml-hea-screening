# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2025-05-11

### Added
- Initial public release
- Language model training with MatSci BERT
- Classical ML baselines (LightGBM, Gradient Boosting, Lasso)
- Transformer-based regression models
- Bayesian Optimization for virtual screening
- Feature importance analysis (SHAP)
- Self-attention visualization
- Jupyter notebooks for workflows
- Comprehensive documentation

### Features
- 415 HEA training compositions
- 150K MLM pre-training dataset
- 9.12M virtual alloy candidates
- Pre-trained model weights
- Configuration system
- Automated setup script

### Model Performance
- **Language Model (Skip Connections)**: R² = 0.762, MAE = 83.4 HV
- **LightGBM**: R² = 0.773, MAE = 73.9 HV
- **Gradient Boosting**: R² = 0.748, MAE = 78.0 HV
